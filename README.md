# Antonymous Fruit-Picking Robot

## Overview
This project was completed as the final project for **WPI RBE 1001** and involved the design and
implementation of a fully autonomous fruit-picking robot operating in a simulated orchard
environment. The system integrated mechanical design, sensing, and control logic to detect,
navigate toward, and collect fruit without human intervention.

The project was completed in collaboration with **Michael (Mike) Sacca**, with a strong emphasis
on real-world robotics challenges such as reliability, precision, and autonomous decision-making.

> **Note:** Full source code, hardware configuration files, and implementation details are available
> in the repository for those interested in a deeper technical breakdown.

---

## System Overview
The robot was designed as a complete autonomous system using **VEX V5 hardware** and developed
in **VS Code**. Multiple subsystems were coordinated to achieve reliable fruit detection,
navigation, gripping, and depositing within a constrained environment.

Key design considerations included gripper reliability, sensor fusion, autonomous navigation,
and repeatable object handling performance.

## Design Highlights
- Fully autonomous navigation in a simulated orchard environment
- Multi-sensor input for real-time object detection and positioning
- Iterative gripper design focused on speed and handling precision
- Coordinated control of collection and depositing mechanisms
- Emphasis on reliability and repeatability during operation

---

## My Role
- Designed and tested **three gripper prototypes**, selecting the most reliable design based on
  speed and handling precision
- Developed **Python control scripts** for real-time object detection and autonomous navigation
  using multi-sensor input
- Led the design and implementation of the **fruit depositing system**, achieving **92% accuracy**
  in bin deposits
- Contributed to overall system integration and performance testing
